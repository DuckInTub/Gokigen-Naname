# Gokigen-Naname
Gokigen Naname solvers and utilities. Solvers implemented in: Python, Prolog, Prolog + CLP(FD), Clingo.

## Python utilities
The gokigen/ folder contains a python helper module. It has utilities like parsing clingo solutions
and generating clingo constraints from a text representation of a board. The module can be interacted
with via the CLI using:
```
python3 -m gokigen --help
```

## Solution vizualiser
The `vis.sh` script can be used to solve a board and vizualise it via python with matplotlib.
